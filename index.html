HECHO PARA QUE CADA GIRO CUENTE ✳

Publicar en GitHub

Para publicar desde el móvil hace falta un token personal. Se crea una vez y solo puede escribir en los presets de este repositorio.

  1. Abre github.com/settings/personal-access-tokens/new.
  2. Nombre: Ruleta. Repositorio: solo Alejandrlucena/ruleta.
  3. Permisos: Contents: Read and write. Lo demas en No access.
  4. Genera el token y pegalo abajo. Se guarda solo en esta pestana.
